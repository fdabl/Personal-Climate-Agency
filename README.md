# Personal Climate Agency
This repository contains code to reproduce all analyses and figures for the paper Nielsen, K., Ding, J., Ejsing, M., Sekara, V., & Dablander, F. (2026). Personal climate agency in a high-income context.

- `data_cleaning.Rmd` prepares the data for analysis.
- `data_cleaning.html` output of the above.
- `data_analysis.Rmd` runs the analyses reported in the paper.
- `data_analysis.html` is the rendered output of the above.
- `data/`
    - `data_rudersdal_anon.csv` is the de-identified public-use dataset generated by `data_cleaning.Rmd`.
    - `data_rudersdal_new.csv` is the source survey export used by the cleaning script and is not publicly available.
- `output/` is where supplementary tables and intermediate files are saved to.
- `figures/` contains JavaScript code for figures and the resulting pdfs.
